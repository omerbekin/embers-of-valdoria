# Simülatörler, build ve yayın

> CLAUDE.md'den taşındı (2026-10-14, birebir). Genel kurallar CLAUDE.md'de; bu belge komut ayrıntısıdır. Denge simülasyonu, build/kod bölme, GitHub Pages ya da Cloudflare yayını işinden önce oku; ayrıca `docs/balance.md`, `cloudflare/README.md`.

## Build
- `npm run build` — tip kontrolü + üretim derlemesi (`dist/`). **Kod bölme (hızlı açılış, 2026-10-10):** ilk indirmede yalnızca Phaser (kendi parçası, `vite.config.ts > codeSplitting`) + ana menü; diğer sahneler `src/game/lazy-scenes.ts` yer tutucularıyla ilk gerektiğinde iner (menü hazır olunca arka planda önceden), Codex `src/wiki/open.ts`, debug menüsü `src/ui/debug-entry.ts`, multiplayer ağ katmanı `src/game/mp-net.ts`, ses modülü (main.ts) ayrı parçada. Yeni sahne = `lazy-scenes.ts > LOADERS`'a ekle; ana menüden (MainMenuScene, main.ts) sahne sınıfı ya da ağır modül (BattleScene, campaign-ui, menu-ui, endless-session, audio) statik içe aktarılmaz (hafif olanlar: `menu-text.ts`, `kv-storage.ts`).

## Testler
- **Hızlı / yavaş ayrımı (2026-10-14):** `vite.config.ts > test.projects` iki proje tanımlar: `fast` (yavaşlar hariç her şey) ve `slow` (yalnızca `vitest.slow-list.ts > SLOW_TESTS`: balance, balance-b, campaign-balance, campaign-difficulty, endless-balance, golden). `npm test` ikisini birden koşar (CI aynen her şeyi koşar); `npm run test:fast` = `vitest run --project fast` (~13 sn), `npm run test:slow` = `vitest run --project slow` (~108 sn; süreyi tek başına campaign-difficulty belirler). Tek dosya: `npx vitest run tests/<dosya>.test.ts`. Havuz `pool: 'threads'` (forks'tan ~%17 hızlı); `isolate: false` testleri kırdığı için kullanılmaz.
- Yeni bir test dosyası tek başına ~3 sn'yi aşıyorsa (denge simi, büyük kayıt karşılaştırması) `vitest.slow-list.ts`'e eklenir; test yeniden adlandırılmaz.
- `npm test` — vitest testleri (motor saflığı denetimi dahil: `src/engine` içinde Math.random/Phaser/DOM yasak)

## Simülatörler
- `npm run sim` — headless denge simülatörü (`src/sim/cli.ts`): rastgele takımlı savaşlar, iki taraf yapay zeka; sınıf kazanma oranı (4e 4; hedef bantlar `data/balance.json`: kazanma %44-56, bedelsiz temel saldırı %20-45, normal skill %15-35, durumsal destek %8-25, ultimate hazır olana kadar yaşayanlarda en az bir kez ≥%50, süre 35-50 tur; karakter karşı karakter tablosu yalnızca ezici eşleşmeleri işaretler), kompozisyon, skill kullanımı raporu. Argümansız 2 x 10.000 savaş; seçenekler: `npm run sim -- <savaş sayısı> <ilk seed> [oyuncu] [düşman]`. `tests/balance.test.ts` + `tests/balance-b.test.ts` aynı ölçümü test olarak korur.
- `npm run sim:campaign` — sefer simülatörü (`src/sim/campaign.ts`): seferi baştan sona YZ ile oynar (oyuncu vekili Medium = iyi oyuncu, Easy = ortalama oyuncu), üç zorluk; düğüm başına ilk deneme kazanma, deneme sayısı, kalan can, rota bitirme. Hedefler `data/campaign/balance.json`; testler `tests/campaign-balance.test.ts`, `tests/campaign-difficulty.test.ts`.
- `npm run sim:endless` — Endless simülatörü (`src/sim/endless.ts`, CLI `endless-cli.ts`): koşuları YZ ile baştan sona oynar (iyi oyuncu vekili: ödül/dükkân/Equip best/kalıntı), dalga başına kazanma, ulaşma eğrisi, p10/p50/p90, elit/boss düşüşü, sınıf ve kalıntı etkisi; `--compare` (item'siz / kalıntısız), `--cfg=dosya.json` (veriye dokunmadan ayar denemesi). Hedef bantlar `data/endless.json > balance`; test `tests/endless-balance.test.ts`.

## Yayın
- Yayın: her değişiklik önizleme linkine yayınlanır (GitHub Pages otomatik; Cloudflare https://eov.backinn.com.tr elle `npm run deploy:cf`), Ömer telefondan oynar.
- Yayın: `main` dalına push → GitHub Actions test + build → GitHub Pages (`.github/workflows/deploy.yml`). Test kırmızıysa yayın olmaz.
- Yayın (Cloudflare, ücretsiz plan, elle): `npm run deploy:cf` — build + dosya sınırı denetimi + tek `wrangler deploy`: oyun https://eov.backinn.com.tr (Workers Static Assets) ve multiplayer lobisi aynı Worker'da `wss://eov.backinn.com.tr/lobby` (`cloudflare/wrangler.toml`, alan adı Custom Domain olarak otomatik bağlanır). Bir kez önce: `npm --prefix cloudflare install` + `npm --prefix cloudflare exec -- wrangler login` (Ömer onaylar). Hesaba dokunmadan kuru deneme: `npm --prefix cloudflare run check`. Yerel: `cd cloudflare && npm run dev` (127.0.0.1:8787, önce `npm run build`). Adımlar ve ücretsiz plan sınırları: `cloudflare/README.md`. **Yalnızca ücretsiz plan (Ömer): ücretli Cloudflare özelliği eklenmez.**
