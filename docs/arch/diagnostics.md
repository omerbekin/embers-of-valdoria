## İstemci (`src/diag/`)
- `diag-core.ts` (saf, Node'da test: `tests/diag.test.ts`): iz halkası (son `maxCrumbs` = 200, localStorage `eov.diag.crumbs.v1`, her iz sekmenin oturum kimliğini taşır), onay (`eov.diag.v1`: consent, noticed, device), oturum işaretleri (`eov.diag.sessions.v1`: sekme başına temiz/canlılık), rapor kurma (32 KB sınırı: en eski izler düşer), kısıtlama, Copy Log metni.
- `diag.ts` (tarayıcı): `installDiag()` main.ts'nin en başında; `attachDiagGame(game)` oyun kurulunca (sahne geçişleri `SceneManager.start` sarılarak iz olur: `scene <anahtar> (seed, mod, enc, node)`, sahne kurulunca `ready`). Pencere `error` / `unhandledrejection`, oyun döngüsü güvenlik ağı (`src/ui/loop-guard.ts`, yeni ileti bir kez) -> iz + rapor. Sefer: yeni / yükleme (Continue, Load Game) / yenilgi sonrası yükleme / savaş başlangıcı (karşılaşma + düğüm) `src/game/campaign-session.ts`.
- **Dışarıdan iz eklemek:** `import { logEvent } from '../diag/diag'; logEvent('gl', 'webglcontextlost')` (tür kısa: scene, ready, battle, campaign, cloud, error, rejection, gl, hidden, visible, report, info). Ayrı rapor gerekiyorsa `report('webglcontextlost', ileti)` (onay kapalıysa göndermez).
- **Bulut kaydı (2026-10-25; `src/cloud/cloud.ts`, bağlantı `main.ts > initCloud({ diag })`):** iz türü `cloud`: `sign-in ok` / `sign-in error <neden>`, `session ok, cloud rev N|none, local rev N`, `session ended (sign-out | account-deleted | expired | http-401)`, `decision <none|upload|download|merge|ask|refuse [neden] [key]>: cloud rev N [anahtar=sürüm,...] slots N, local [...] slots N`, `apply ok (backup yes/no) [...] slots N` / `apply failed <neden> [key]`, `upload ok rev N` / `upload http <durum> [kod] [(conflict round N)]`, `status <offline|error|newer-version|needs-choice> [kod]`. Raporlar (Worker tür listesi değişmedi: tür `error`, ileti `cloud <kod>: ...`; kod başına oturumda bir kez): `auth-error` (?auth=error, neden kodu), `error` durumunun kodu (`me-<http>`, `save-<http>`, `save-shape`, `apply-<neden>`, `cloud-<neden>`, `conflict-loop`, `too-large`, `put-<http>`/sunucu kodu, `load-failed`, `no-cloud-save`, `upload-guard`), `newer-version` (refuse newer-schema / apply / 409 schema-older), `cloud_apply_mismatch` (download/merge sonrası paketteki sefer yuvası sayısı > yereldeki), `upload-guard` (karar upload ama bulutta ilerleme var, yerelde yok: PUT yapılmaz). İletiler yalnızca teknik: karar türü, rev, http durumu, hata kodu, anahtar ADI + sürümü, yuva sayısı; kayıt içeriği, görünen ad, e-posta, kullanıcı / sağlayıcı kimliği, çerez YOK (dışarıdan gelen kodlar `safeCode` ile süzülür). Test `tests/cloud-client.test.ts` > "tanılama".
- **Çökme tespiti:** açılışta sekme kendi işaretini "temiz değil" yazar; görünürken 15 sn'de bir canlılık tazelenir; sayfa gizlenince / kapanınca "temiz". ## Worker (`cloudflare/`)
- `POST /diag` (`src/index.ts > handleDiag`, saf kurallar `src/diag-logic.ts`, test `tests/diag.test.ts`): köken izni (`ALLOWED_ORIGINS`: embersofvaldoria.com, omerbekin.github.io, localhost), 32 KB, şema doğrulama (rapor yalnızca bilinen alanlardan yeniden kurulur, fazlası atılır), cihaz başına saatte 12 rapor (KV sayacı), anahtar `r:<sunucu ISO zamanı>:<rastgele>`, `expirationTtl` 30 gün. **IP (`CF-Connecting-IP`) ve `req.cf` okunmaz.** Okuma ucu YOK.
- KV bağlaması `DIAG` (`wrangler.toml > [[kv_namespaces]]`), `run_worker_first` içinde `/diag`. Ücretsiz KV: günde 100.000 okuma, 1.000 yazma (rapor başına 2 yazma), 1 GB.
- **Bir kez kurulum:** `npm --prefix cloudflare exec -- wrangler kv namespace create eov-diag` -> çıkan `id`'yi `cloudflare/wrangler.toml` içindeki `REPLACE_WITH_DIAG_KV_ID` yerine yaz -> `npm run deploy:cf`. (Yazılmazsa deploy hata verir.)
- **Raporları okumak:** `npm run diag:pull` (en yeni 15 rapor, özet + son 12 iz), `npm run diag:pull -- --limit 50`, `-- --full` (tam JSON), `-- --kind previous_session_crashed`. Yerelde giriş yapılmış wrangler kullanır (`cloudflare/scripts/diag-pull.mjs`).
- Yerel deneme: `cd cloudflare && npm run dev` (yerel KV), oyunu `http://localhost:5173/?mpserver=ws://127.0.0.1:8787` ile aç, Settings'te aç, Debug > Data > Send test report; `npx wrangler kv key list --binding DIAG --local`.
