# Codex için

Bu proje Embers of Valdoria (TypeScript + Phaser 3 + Vite). Proje sahibi Ömer; onunla Türkçe konuş. Kodu Claude yazar.
Senin bu projedeki işin: skill animasyonlarını (VFX kare dizileri) incelemek ve gerektiğinde yeni kare dizisi çizmek.

Başlamadan oku: `docs/anim-review/README.md` (süreç, not formatı, kurallar). Sıra kimde: `docs/anim-review/board.md`.

**"board'a bak"** komutu: board.md'de sırası Codex'te olan (`incele`, `kontrol`, `yeni-cizim`) her skill'i README'deki
aşama tarifine göre yap, notunu yaz, board'u güncelle. Bitince Ömer'e tek satır özet ver (hangi skill, yeni durum).
Sırası sende olan iş yoksa "sende iş yok" de.

Sabit kurallar:
- Oyunun sesi hep kapalı (yöntem README'de).
- Yalnız `docs/anim-review/` altına yaz. Kod, `assets/`, `data/` dosyalarını değiştirme.
- Git işlemi yapma.
- Oyun içi yazılar İngilizce, notlar Türkçe.
